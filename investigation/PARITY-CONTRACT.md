## Accepted representative contract (T3)

Retain all 314 upstream route patterns and all backend/server implementations. Nift owns published docs inputs/projections and their manifest; TanStack owns request-time shell/page SSR, Router, Query and interactive components. Authored and agent-maintained sources must remain authoritative after hydration and client navigation. All retained static asset bytes must survive unchanged; compiled bundle names may change through the bounded adapters.

Compare titles, canonical/SEO values (normalize only differing local harness origins), headings, semantic component controls, tabs/code-copy, search transport, mobile/theme controls, Router navigation without document reload, Query view changes, Markdown download bytes, redirects/404/API statuses and per-session partner seeds. Distinguish source-derived coverage from live backend integration. No production database/auth/AI use is authorized. Full corpus and broader dynamic/route-lifecycle contracts remain T4–T7 obligations.
