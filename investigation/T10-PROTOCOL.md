# T10 final measurement protocol

Five serialized samples per implementation/workload. Installed pinned dependencies, maintained source inputs and OS page cache remain present. Warm full forces Vite and all Nift resolution, projection derivation and composition. Fresh removes defined owned application/build/output caches, includes cleanup in the command, and forces the same complete publication. Unchanged invokes each normal production command. Infrastructure deployment, DB migration and live edge cache purge are excluded.

The upstream site reads documentation at runtime. Body 1/10/100, navigation config, title metadata, synchronized docs input and route lifecycle therefore use its native cache/ingestion workflow, not a Vite rebuild. The benchmark helper is compiled against the pinned, unchanged upstream modules. An in-memory build-only export shim exposes private buildDocsPathManifest/buildDocsManifest/isDocsManifest functions without changing their bodies or files. Ordinary valid paths refresh the lighter path manifest. Full redirect metadata is refreshed only for renamed/deleted-path resolution. The earlier eager full-redirect smoke remains diagnostic evidence and is not a normal-body result.

Each native case primes a defined 100-document Query working set, config and path artifact outside timing; missing-path cases also prime redirect metadata. Samples invalidate real owned local R2 content/artifact caches, read changed inputs/config, and refresh the appropriate original artifact. Captured public GET fixtures stand in for GitHub, and the R2 RPC body bridge preserves single-use bodies. The timed window includes the complete compiled helper startup, invalidation/refresh and disposal; its internal refresh component is retained separately. Live network/edge latency and end-user SSR are not included. This is a local native-update comparison, not an upstream production rebuild or dev/HMR measurement.

Nift cases time the complete production publisher, including scans, required retained Vite bundling, static asset publication, authored resolution/derivation or maintained-projection preparation, metadata and Nift composition. Shell/Footer, ThemeToggle island and authored blog collection changes require production bundling in all three implementations. The agent retains the necessary original blog sources and React component representations; it does not derive the 7,527 migrated doc projections routinely.

Mutations use real pinned content/components, deterministic sample markers and a recoverable external journal. Authored reference dependencies may update multiple framework projections. Agent edits update maintained AST/original/download fields explicitly before timing. Docs synchronization updates a controlled content input plus maintained digest registry; public-network capture is outside timing. Add/rename/delete update source registries and captured tree fixtures. All maintained bytes are restored in finally blocks, and complete derived publication is restored between workloads. Byte-changed/add/delete fan-out is recorded outside timing; forced recomposition can change no bytes.

GNU time records maximum individual process/phase RSS across the same complete command window, never summed. A 50ms descendant sampler separately records tree RSS in that window, excluding unrelated user processes; short peaks can be missed. Medians and min/max ranges use five samples, with raw records, phase costs and machine load retained. Results from different scopes are labeled explicitly rather than pooled. No OS-wide cache flush or exclusive-machine claim is made.

Native ordinary-path and missing-path smoke checks pass before starting the final campaign. The former refreshes the path artifact without scanning every doc for redirect aliases. The final report must keep upstream advantages, retained bundler costs, source-model tradeoffs and live-integration limits visible.

Preflight alignment before any native/changed-input samples: both the edit driver and native reader use the same persisted 100-file React authored-input plan, beginning with the non-default background-fetching guide whose source has five framework dependents. Native body/metadata/config reads assert their mutation marker. Completed full/fresh samples are unaffected by this input-plan correction.

Lifecycle mutations use the independent Comparison document, which has no incoming source references, and update its real React navigation entries. Rename tests remove the old canonical path without inventing a redirect alias; missing-path resolution still uses the original redirect lookup.
